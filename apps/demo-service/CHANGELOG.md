# @gracesoft-sentinel/demo-service

## 0.1.0

Initial release. Demoes Sentinel Concierge and Sentinel Cook side by side
in a single chat provider's chat window, via `@gracesoft-sentinel/
agent-switcher` — a chatter switches which agent they're talking to with a
command (`/concierge`, `/cook`) or bare passphrase (`concierge`, `cook`).
Single-tenant, one business config, both agents wired to the same real
providers (OpenAI, Google Calendar) as the standalone services.
