GraceSoft Sentinel Chat

Two AI chat agents — Sentinel Concierge (FAQ answering + booking) and Sentinel Cook (dish-photo recipe generation) — exposed as webhook-driven HTTP services over WhatsApp, Telegram, and SMS.

11 / 11 milestones complete 3 channel adapters 2 AI providers Multi-tenant ready

What this API is

Each agent doesn't speak "WhatsApp" or "OpenAI" directly. Inbound messages from any supported channel are normalized into one shared shape before an agent ever sees them, and the agent's reply is translated back into that channel's own format on the way out. That's the whole design: your integration surface is the webhook you point a channel at — everything else (which AI provider answers questions, which calendar holds bookings, which businesses share a deployment) is configuration, not code.

The two agents

AgentServiceDefault portDoes
Sentinel Concierge concierge-service 3000 Answers FAQs grounded in a business's own knowledge base, resolves booking requests against Google Calendar availability, and escalates anything it isn't confident about.
Sentinel Cook cook-service 3001 Identifies a dish from a photo and returns a full recipe (ingredients, steps, substitutions, nutrition), handles dietary-adjustment follow-ups, builds a consolidated grocery list across a session's recipes, and can optionally retrieve a user's own saved recipes from Google Drive via semantic search.

Supported channels

ChannelPackageTransportNotable limits
WhatsAppchannel-whatsappWhatsApp Cloud APIFull support: text, media, interactive buttons/lists, voice notes
Telegramchannel-telegramTelegram Bot APIFull support: text, media, inline keyboards, voice notes
SMS / MMSchannel-smsTwilioPlain text only — quick replies degrade to a numbered list the chatter replies to by typing a number

All three implement the same ChannelAdapter interface and pass the same shared contract test suite, so behavior — quick-reply degradation aside — is guaranteed consistent regardless of which one a message arrived on.
