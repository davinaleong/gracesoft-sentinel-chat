## Dark Mode

Fonts stay the same in dark mode. The Indigo and Black scales above are reused as-is — dark mode is a different assignment of roles to the same swatches, not a new palette. Shades below are chosen so every text/background pairing clears WCAG AA (4.5:1 for body text, 3:1 for large text and UI components); ratios are noted for reference.

### Surfaces

Background: Black 950 (#000000) — use Black 900 (#0e0e0e) instead for a softer, less OLED-harsh base
Elevated / Card: Black 900 (#0e0e0e)
Hover / Secondary surface: Black 800 (#1e1e1e)
Border / Divider: Black 700 (#393939) — decorative only, not a text-contrast pairing

### Text

Primary: Black 50 (#ffffff) — 19–21:1 on all surfaces above
Secondary / Muted: Black 400 (#a3a3a3) — 7.6–8.3:1
Disabled / Placeholder: Black 500 (#6f6f6f) — 3.8–4.2:1, large text/UI only, not for body copy

### Accent (Indigo)

Text / Links / Icons: Indigo 400 (#8d80fe) — 5.3–6.7:1 across surfaces
Hover / Active text: Indigo 300 (#b1a8ff) — 7.9–9.9:1
Primary button fill: Indigo 600 (#5544ed) with Black 50 (#ffffff) text — 6.1:1, matches the light-mode primary button color
Focus ring: Indigo 400 (#8d80fe)

Avoid Indigo 500/600 as text or icon color directly on dark surfaces — contrast drops to 2.7–4.8:1, below AA for body text.
